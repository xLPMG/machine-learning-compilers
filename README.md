# Machine Learning Compilers

To learn more about this project, please refer to our [our documentation.](https://xlpmg.github.io/machine-learning-compilers/).

This code was largely developed *WITHOUT* the help of AI tools. Two main reasons for that:
- as an educational project, the focus was on our own understanding and learning process rather than a finished product.
- the LLMs at the time were not reliable or capable enough to meaningfully help with highly optimized assembly code.
